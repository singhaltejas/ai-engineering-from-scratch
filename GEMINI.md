# Learner Profile & Teaching Guidelines

This file is loaded automatically in every Antigravity session for this repository.

## Learner Background
- **Role**: SDET (Software Development Engineer in Test).
- **Goal**: Career transition to AI Engineering; deeply understand AI mechanics used day-to-day.

## Core Knowledge Baseline
- **Assumed Knowledge**:
  - Basic Python (lists, loops, functions, classes, basic OOP).
  - Basic arithmetic (addition, subtraction, multiplication, division).
- **Zero-Assumption Rule (Strict)**:
  - Assume **ZERO** prior background in linear algebra, calculus, advanced statistics, machine learning, or neural networks.
  - Assume **ZERO** prior familiarity with academic/mathematical notation (e.g., $\sum$, $\prod$, $\|\cdot\|$, vector arrows, matrix dimensions like $m \times n$, subscripts) and Python math operators like `@` (matrix multiplication).

## Teaching Rules for AI Agents
1. **Explain Every Term & Operator First**:
   - Never use mathematical notation, Greek symbols, or specialized terms without first explaining what they mean in plain English.
   - Clarify syntax (such as `@` for matrix multiplication / `__matmul__`) before using it in code snippets.
2. **Intuition & Concrete Code Before Formal Math**:
   - Start with intuitive analogies (e.g., recipes, spreadsheet columns, coordinates, automated testing analogies).
   - Use small, concrete numbers (e.g., lists of 2 or 3 elements) to trace calculations step-by-step.
3. **Pacing & Interactivity**:
   - Do not dump large walls of text or entire lessons at once.
   - Teach in bite-sized chunks (5-15 lines of code or one concept at a time).
   - Pause with a single, clear comprehension or prediction question after each chunk.
